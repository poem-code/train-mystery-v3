## 一、先定「什么算完成」

不按技术模块排，按三条上线硬标准排：

| 标准 | 含义 | 现状 |
|---|---|---|
| **① 能提审** | 材料齐、无隐私风险、包体合规 | 差得最远（10%） |
| **② 首 3 局不劝退** | 0—10 分钟体验留得住人 | 基本达标（玩法闭环 100%、打击感已有） |
| **③ 第 10 局还有新东西** | 长线新鲜度 | 差得第二远（内容 70%，但**没有跨局累积**） |

**关键判断**：现在的内容量其实够撑 5—8 局，真正缺的不是"更多敌人"，而是**跨局累积与目标感**。玩家第 5 局之后没有"我在变强"的证据——图鉴、成就、每日挑战、建造全都缺。所以第二轮优先做长线，而不是继续堆敌人。

## 四、逐条方案

### A. 美术：三步走，不一次性推倒

现在的 `draw.figure(ctx, x, y, size, figureId, color)` 是**唯一绘制入口**，这是最大的资产——换图集只改这一个函数，全工程不用动。方案就建在这个契约上。

**A1 · 矢量再压一层（0 外部依赖，可立即做）**
- 敌人按 `trait` 给不同**轮廓原型**（重甲=方肩宽体、吸血=细长带尾、群袭=多体簇、镜影=对称镜像、自爆=圆胀+裂纹），现在 19 个敌人只靠颜色区分，形不区分
- 受击时分部位变色（不是整体闪白），命中点定向压暗
- 背景三层视差：远=横纹与雾、中=车窗外流动光带、近=扶手/座椅剪影；随节点移动做 2—3px 位移
- 节点图标从字符字形（⚔ ✦ ?）换成 `draw` 里手绘的 8 个几何图形，与敌人同一套线条语言

**A2 · AI 立绘 + 图集管线（推荐，我可以直接做）**
这是把美术从 25% 拉到 80% 的最短路径，且不需要你去找画师：

1. **风格锚定**：先出 3 张样张（普通/精英/Boss 各一），统一 prompt 模板——冷灰蓝主色 + 单一暖色高光 + 厚涂颗粒 + 无明显背景（便于抠图）+ 反派感但非写实血腥
2. **批量**：19 敌人立绘 + 3 张场景背景 + 8 个节点图标
3. **管线** `tools/build-atlas.py`：
   - 去背 → 统一画布高度 → 紧凑打包（shelf packing）→ 输出 `atlas.png` + `manifest.json`
   - manifest 记每张的 `rect / 锚点 / 视觉重心`，绘制时按视觉重心对齐而不是按框对齐（否则高瘦敌人会"浮"在半空）
4. **运行时**：`assets/manifest.js` + `draw.sprite()` 异步加载（`tt.createImage`），**未加载完成时自动回退矢量剪影**——绝不允许白屏或空位
5. **包体**：19 张 512px webp 约 40—70KB/张，合计 ≈1.2MB，加背景控制在 **3MB 内**；图集走分包

**A3 · 帧动画（可选）**
每个敌人 4 帧（待机 2 + 受击 1 + 死亡 1），图集按行排列。做完 A2 再评估——**先把形做对，再谈动**。

### B. 音频：补 BGM 与音量分层

**B1 · 三首 BGM**（复用 `tools/gen-audio.py` 的合成器，新增循环生成）
- 主城：低频蒸汽 + 缓慢三音琶音，60s 循环，无缝接尾
- 路线/事件：稀疏拨弦 + 风噪，45s
- 战斗：脉冲鼓点 + 不协和长音，30s，随血量低于 30% 提高一层音高（紧张感）

**B2 · 音量分离**：现在只有 `meta.soundOn` 单开关，拆成 `bgmOn / sfxOn` 两个，设置页加滑杆（3 档即可）

**B3 · 音效分层**：命中音 = 基础冲击 + 按敌人材质叠加（金属/血肉/玻璃），现在只有一个 `hit`

---

### C. 内容：先做"组合"，再做"数量"

**C1 · 三套主题（锈蚀列车 / 冰封车厢 / 裂隙边缘）**
- 主题决定：配色、节点权重、敌人池、事件池、Boss 池、背景、BGM 变体
- 每局按 seed 选主题，玩家在"观景台"（D4 解锁）可指定下次主题
- 收益：同样的 19 个敌人×3 套配色与池子，观感差异远大于再堆 10 个敌人；且是纯数据改动（`data/themes.js`）

**C2 · 精英词缀系统（性价比最高的一项）**
现在精英 = 高血量普通怪。改成：**精英 = 基础敌人 + 1 个词缀**
- 词缀池（8 个）：狂暴（伤害+30%，每回合自伤 2）、护盾（每 3 回合立盾 10）、毒化（命中带 3 回合持续伤害）、召唤（首回合召唤一只小体）、迅捷（先手，首回合攻击两次）、镜像（命中反弹，复用镜影逻辑）、贪婪（金币×2 但攻击+20%）、残响（死亡后以 40% 血复活一次）
- 词缀是**数值修饰 + 复用已有 trait 分支**，不新写战斗流程 → 风险低、组合数从 4 精英变 4×8=32 种
- 精英节点显示词缀标签，玩家能提前决策（打不打）

**C3 · 二次扩容**：敌人 19→30、事件 21→32、强化 24→34、遗物 18→26
硬约束（已有机制守）：新增 `trait` 必须在 `state.js` 有分支，新增 `effects` 字段必须在 `EFFECTS` 白名单。测试会直接红——这条别放松。

**C4 · 事件链**：3 条 3 段式连续事件（同一局内按层推进），给叙事密度。当前 21 个事件全是独立单次，缺少"我还记得上次那个"的记忆点。

### D. 长线：这是当前最大的缺口

**D1 · 永久图鉴** `progress.codex`
- 敌人：未遇见（剪影）/ 已击败（立绘+特性说明）/ 击败 5 次（解锁该敌人的战斗提示）
- 遗物/强化：解锁即入库，未获得显示轮廓
- 图鉴进度给以太奖励（每 10% 一次），**这是把"收集"变成"变强"的桥**

**D2 · 成就 12 条** `progress.achievements`
- 例：无伤通关 Boss、单局 3 遗物、低精神（<30）通关、首次击败某 Boss、连续 3 日游玩
- 奖励以太 + 头像框/称号（本地展示），**不做战力奖励**，避免破坏平衡

**D4 · 建造扩容**：3 模块 → 5 模块
- 现有：餐车（饱食）、医务（营地回血）、引擎（以太）
- 新增：**货舱**（开局多带道具，Lv1 药+1 / Lv3 重战卡+1 / Lv5 秒杀卡+1）、**观景台**（解锁主题指定 + 每日挑战入口）
- 这是把"局外成长"从 3 条线性数值变成有选择的分支

**D3 · 每日挑战**
- 日期做 seed → 全服同一条路线（本地一致即可，不需服务端）
- 3 个限制条件（如：无强化通关 / 只有 60 血 / 敌人伤害+25%）
- 独立记录 + 连续完成天数；**排行榜暂不做**（见第七节）

### E. 平台与上线

| 项 | 现状 | 要做 | 依赖 |
|---|---|---|---|
| E1 广告位 | 常量占位 `REPLACE_WITH_YOUR_AD_UNIT_ID`，`isConfigured()` 已降级 | 填 AppID + 广告位 ID，真机验 3 次失败/取消/成功路径 | **需你提供** |

| E3 云存档 | 无 | `tt.setUserCloudStorage` 做跨端备份；**本地优先、云为兜底**，避免弱网卡启动 | 需 AppID |
| E4 埋点 | 无 | 漏斗：启动→主城→出发→第 1 层→Boss→结算→次日回访；`tt.reportAnalytics` 字段名固定 | 需 AppID |

**E5 那条特别提一句**：小游戏上线后最痛的是"用户说闪退但你复现不了"。环形日志 + 一键复制成本极低，收益极高，属于必须做的。

### F. 工程健壮性（提审前必须量出来）

- **F1 性能预算**：低端机 ≥30fps；单帧绘制指令 ≤400；图集加载后内存峰值 ≤120MB。用 `engine.__tick` 计数 + 真机 `tt.getPerformance()` 双看
- **F2 包体预算**：主包 ≤4MB（图集走分包，留 20MB 上限余量）
- **F3 兼容矩阵**：iOS/Android 各 2 档机型 × 3 档分辨率（390×844 / 360×640 / 768×1024），全部截图走查（现有 `preview.html` 已支持模拟 `tt`，扩分辨率参数即可）
- **F4 灰度**：先分享链接测 50 人，只看两个数——**第 2 局开始率**、**崩溃率**

## 八、明确不做，及原因

| 不做 | 原因 |
|---|---|
| 排行榜、内购 | **必须先有服务端 reward token 校验**。没有就直接上，本地存档可改，那是漏洞不是功能 |
| 多人 / 好友 | 审核成本高、同步复杂度高，收益不确定 |

| 30 秒以上剧情演出 | 抖音场景是碎片时间，长演出会拉高流失 |

## 九、风险与对应对策

| 风险 | 表现 | 对策 |
|---|---|---|
| AI 立绘风格不统一 | 19 张放一起像 5 个画师画的 | 先 3 张样张对齐再批量；统一 prompt + 统一后期调色脚本 |
| 图集与矢量混用割裂 | 部分敌人有立绘、部分还是剪影 | 一次性全量切换 + feature flag `config.useAtlas`，可一键回退 |
| 主题扩张导致失衡 | 某主题敌人过强 | 每主题单独跑 400 局，通关率不在 45—60% 就不放 |
| 精英词缀叠加过强 | 残响 + 狂暴的精英打不动 | 词缀权重分级，同一精英最多 1 个，Boss 不吃词缀 |
| 内容扩张引入静默失效 | 新字段名写错，词条不生效 | 已有数据一致性测试守（白名单 + trait 反查），**新增内容必须先过测试** |

## 十、一句话结论

**当前代码侧已可交，缺的不是"更多内容"，而是「跨局目标感」和「可提审的材料」。**
第一轮我就能把长线（图鉴/成就/建造）、表现（矢量分层/音频）、系统深度（精英词缀）全部做完，不需要你给任何东西；第二轮才需要你定美术方向，第三轮才需要 AppID。
