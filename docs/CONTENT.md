# 内容总表

> 全部条目由 `js/game/data/*.js` 导出。本表用于策划对齐、图鉴文案核对、以及改数据后回查。
> **数据改了这里必须同步**，否则答辩/文档与实现不一致。

内容总量：**19 敌人 + 8 词缀 + 18 遗物 + 24 强化 + 21 事件 + 7 每日条件 + 12 成就**，
图鉴收录 **61 条目**（敌人 19 + 遗物 18 + 强化 24）。

## 二、精英词缀（8）

4 精英 × 8 词缀 = **32 种组合**。每个字段在 `state.js` 都有真实分支，一致性测试用正则反查守着。

| id | 名称 | 效果 | 实现字段 |
|---|---|---|---|
| frenzy | 狂暴 | 伤害 +30%，但每次出手自伤 2 点 | `damageMul` / `selfDamage` |
| bulwark | 壁垒 | 每 3 回合立起 12 点护盾 | `shieldEvery` / `shieldAmount` |
| venom | 毒化 | 命中后你每回合额外掉 3 血，持续 3 回合 | `poison` |
| summon | 召唤 | 首回合与第 4 回合各召一次扑咬，额外 5 点伤害 | `summonTurns` / `summonDamage` |
| swift | 迅捷 | 首回合抢先攻击两次 | `swiftTurn` |
| mirrorA | 镜像 | 你命中时反弹 4 点伤害 | `reflect` |
| greedy | 贪婪 | 赏金翻倍，攻击力 +20% | `goldMul` / `damageMul` |
| echo | 残响 | 首次死亡时以 40% 生命复活 | `reviveRatio` |

设计意图：**词缀是「换打法」不是「加血量」**。
狂暴逼你速杀，壁垒逼你算节奏，毒化逼你留药剂，残响逼你把爆发留到最后一段。
战斗界面在敌人名下方显示 `词缀 · 名称` 徽标，玩家不需要背。

## 六、每日挑战

### 限制条件（7，每次开局抽 3 个）

| 名称 | 效果 |
|---|---|
| 脆弱躯壳 | 生命上限 -25 |
| 荒芜地带 | 每次移动额外消耗 3 饱食 |
| 凶暴之敌 | 敌人伤害 +20% |
| 稀薄空气 | 精神消耗翻倍 |
| 身无分文 | 开局没有以太碎片 |
| 思路受限 | 每次强化只有 2 个候选 |
| 物价飞涨 | 商店价格翻倍 |

### 规则

- **解锁条件**：观景台 Lv.1
- **种子**：`FNV-1a("YYYY-MM-DD")`，同日全球一致，跨日必不同
- **抽取**：用同一 seed 做 LCG 洗牌取前 3 个
- **奖励**：`baseReward 90 + rewardPerLayer 8 × 层数`，观景台每级 +10%
- **不改主档**：开局 `snapshotWallet()` 快照，结算 `restoreWallet()` 还原，
  每日奖励单独发放，**不消耗也不计入本局以太与道具**
- **不信任存档**：`sanitizeDaily` 按 `dateKey` 重推导限制条件，改档无法伪造

设计意图：每日挑战是「用熟悉的内容做不熟悉的题」，
不新增内容却能把老玩家的复玩动机拉起来，成本最低的长线手段。

## 七、成就（12）

声明式：`metric` + `target` + `reward`。`computeMetrics()` 产出全部指标，
`evaluateAchievements()` 比对并发放，**不重复发放**（测试守着）。

| 名称 | 指标 | 目标 | 条件 |
|---|---|---|---|
| 初次穿越 | bossClears | 1 | 首次击败关底首领 |
| 熟门熟路 | bossClears | 3 | 累计通关 3 次 |
| 老乘客 | bossClears | 8 | 累计通关 8 次 |
| 抵达尽头 | bestLayer | 8 | 抵达最深一层 |
| 满载而归 | maxRelics | 5 | 单局携带 5 件遗物 |
| 构筑成型 | maxEnhancements | 10 | 单局获得 10 项强化 |
| 毫发无伤 | perfectBossWins | 1 | 满生命击败关底首领 |
| 精神临界 | lowSanityClears | 1 | 精神低于 30 时通关 |
| 赤手空拳 | noRelicClears | 1 | 不带任何遗物通关 |
| 博物学者 | codexPercent | 50 | 图鉴进度达到 50% |
| 全知乘客 | codexPercent | 100 | 图鉴进度达到 100% |
| 每日常客 | dailyClears | 3 | 完成 3 次每日挑战 |

**成就只给以太，不给战力**。给了战力就等于给新手设门槛，
而以太只通向「列车升级」这种平滑成长，不会破坏单局平衡。

## 八、图鉴

4 个分页：敌人 / 遗物 / 强化 / 成就。

- 敌人条目未遇见时只显示名称与「尚未遇见」；遇见后显示特性描述，
  并单列「已击败 N 次」——**见得多不等于打得过**，两个数据分开记
- 遗物与强化在首次获得时解锁
- 进度 = 已解锁 / 61，到 25% / 50% / 75% / 100% 各发 60 以太（`config.codex.rewardPerTier`）
- **分页而非滚动条**：低端机 Canvas 手写滚动容易抖，分页更稳（每页 5 条）

## 九、节点类型（7）

| 类型 | 标签 | 字形 | 说明 |
|---|---|---|---|
| battle | 战斗 | sword | 普通战斗，给强化 |
| elite | 精英 | skull | 精英战斗，带词缀，给遗物 + 4 选 1 |

| boss | Boss | boss | 关底，第 9 层 |

节点图标全部是 `draw.nodeGlyph` 画的几何字形，**不用字符**——
低端安卓字体渲染不一致，⚔ ✦ ☠ 这类符号经常出方块或错位。
