# 内容总表

> 全部条目由 `js/game/data/*.js` 导出。本表用于策划对齐、图鉴文案核对、以及改数据后回查。
> **数据改了这里必须同步**，否则答辩/文档与实现不一致。

内容总量：**30 敌人 + 8 词缀 + 26 遗物 + 34 强化 + 32 随机事件 + 3 条事件链（9 段） + 7 每日条件 + 12 成就**，
图鉴收录 **90 条目**（敌人 30 + 遗物 26 + 强化 34）。

## 二、精英词缀（8）

4 精英 × 8 词缀 = **32 种组合**（现在 6 精英，共 48 种）。每个字段在 `state.js` 都有真实分支。

### 事件链（3 条 × 3 段）

链事件**不进随机池**，由 `nextChainEvent` 按「层数 + 段序 + 60% 概率」发出。
进度存在 `run.chains`，白名单化后落盘，读档继续。

| 链 | 第 1 段（L2+） | 第 2 段（L4+） | 第 3 段（L6+） |
|---|---|---|---|
| **检票员的手册** | 座位下的半本手册：收进包里 / 撕下空白页 | 拿着手册的查票员：递给他(险) / 花钱过关 | 终点车厢的补票窗口：补全票（换秒杀卡） / 还回去 |
| **孩子的画** | 一张蜡笔画：收好 / 折成纸飞机 | 画里的那节车厢：走进去(险) / 站在门口看 | 在等你的孩子：把画还给他 / 转身离开 |
| **锅炉的低语** | 地板下的敲击声：也敲三下(险) / 捂住耳朵 | 锅炉检修口：钻进去（耗血） / 关严盖子 | 空着的司炉位：坐进去(险) / 把火压小 |

设计意图：单局 2—4 个事件点，链只覆盖很小一部分，
但只要玩家连着遇到两段，就会记住「上一节车厢那件事」——这是独立事件给不了的东西。
跳段、错过都不惩罚，进度只是「记到第几段」。

## 六、每日挑战

### 限制条件（7，每次抽 3 个）

| 名称 | 效果 |
|---|---|
| 脆弱躯壳 | 生命上限 -25 |
| 荒芜地带 | 每次移动额外消耗 3 饱食 |
| 凶暴之敌 | 敌人伤害 +20% |
| 稀薄空气 | 精神消耗翻倍 |
| 身无分文 | 开局没有以太碎片 |
| 思路受限 | 每次强化只有 2 个候选 |
| 物价飞涨 | 商店价格翻倍 |

### 规则

- **解锁**：观景台 Lv.1
- **种子**：`FNV-1a("YYYY-MM-DD")`，同日一致，跨日必不同
- **奖励**：`90 + 8 × 层数`，观景台每级 +10%
- **不改主档**：开局 `snapshotWallet()`，结算 `restoreWallet()` 还原
- **不信任存档**：`sanitizeDaily` 按 `dateKey` 重推导限制条件

## 六之二、车厢主题（3）

开局前在「车厢主题」弹窗里选，**开局即锁定**（中途改会被利用成「快死了切霜封减伤」）。
以太解锁：锈蚀免费，霜封 150，焚炉 220。每日挑战固定走锈蚀车厢。

| 主题 | 解锁 | 修正 | 内容偏向 |
|---|---|---|---|
| 锈蚀车厢 | 免费 | 无 | 无 |
| 霜封车厢 | 150 以太 | 敌人生命 +15% / 敌人伤害 -15% / 每层多耗 1 饱食 / 开局 +20 以太 | 冰霜系敌人与事件 ×3 |
| 焚炉车厢 | 220 以太 | 敌人伤害 +8% / 战斗金币 +40% / 商店价格 -15% / 开局 +30 以太 | 火与余烬系敌人与事件 ×3 |

**权重而不是硬过滤**：打了别的主题标签的敌人/事件降到 0.4 倍，不排除。
硬过滤会让低层数下池子变空、最后还得 fallback，不如一开始就用权重。

带主题标签的敌人 13 个（冰霜 7 / 焚炉 6），事件 9 个（冰霜 5 / 焚炉 4），其余为通用。

**为什么主题与每日条件共用一套字段**：`state.modsOf(run)` 把 `daily.combined` 与 `theme.mods`
合并成一个修正符（加法相加、乘法相乘），消费点只读合并结果。写两套数值分支迟早会漏一处。

## 八、图鉴

4 个分页：敌人 / 遗物 / 强化 / 成就，共 **90 条目**。

- 敌人未遇见只显示名称与「尚未遇见」；遇见后显示特性描述，并单列击败次数
- 遗物与强化在首次获得时解锁
- 进度到 25% / 50% / 75% / 100% 各发 60 以太
